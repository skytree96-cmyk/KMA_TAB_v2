# 교육 추천 샘플 리포트 점검 (2026-11-04)

## 만든 방법

- 실서비스 코드(gcp-cloudrun)의 리포트 생성 함수를 그대로 호출했다. 개인 PDF는 `individual_report_pdf`, 조직 PDF는 `export_report_pdf`(DB 대신 메모리 결과 6명).
- 프로젝트 설정은 관리자 화면과 같은 `build_project_config`로 만들었다. 목표 수준 3.5(사례 4만 4.0).
- 무작위 응답은 쓰지 않았다. 부족하게 만들 역량만 문항별 점수를 낮게 고정하고, 나머지 역량은 모두 교육 전 3.75 → 교육 후 4.25로 응답했다.
- 과정 카탈로그: `KMA-LIVE-202611`(활성 1,559개). 추천 링크 31개는 직접 열어서 확인했다.

## 의도대로 동작한 부분

- 부족하게 만든 역량만 정확히 골랐다. 4.25점으로 응답한 역량은 한 번도 추천에 나오지 않았고, 목표와 0.25점 차이인 사례 2의 전략적 사고도 빠지지 않았다.
- 목표와의 차이가 큰 역량부터 나왔다. 사례 4는 목표를 4.0으로 올렸더니 차이(1.25 / 1.00 / 0.75)가 그대로 순서에 반영됐다.
- 집합 선호(사례 2)는 공개교육이 먼저, 온라인 선호(사례 3)는 이러닝이 먼저 나왔다.
- 관리자 전용 과정은 실무자 사례(01, 03)에 나오지 않았다.
- 교육 전후 변화에 따라 안내 문구가 달랐다. 사례 4의 하락 역량에는 "교육 전보다 점수가 낮아졌습니다…업무가 바뀌었거나 적용 기회가 줄었는지" 문구가 붙었다.
- 조직 리포트는 3개 역량 × 공개교육·이러닝·단체교육 문의로 9개가 나왔고, 도구·정보·권한(2.00점)을 먼저 보완하라는 문장이 과정 목록 위에 나왔다.
- 개강일이 지난 공개교육은 나오지 않았고, 링크 31개 중 30개는 해당 과정 페이지가 열렸다.

## 확인된 문제

1. **같은 점수 안에서 고르는 기준이 약하다.** 연결 점수(content_fit)가 역량 단위로 거의 같아서 실제 선택은 개강일 빠른 순, 이러닝은 과정 ID 순으로 정해진다. 데이터 분석 이러닝 48개는 모두 0.8점이다. 그래서 제목상 더 맞는 과정이 뒤로 밀렸다.
   - 설득·프레젠테이션 → "미래를 디자인하는 비즈니스 역량 개발 교육"이 나오고, 같은 0.9점의 "OK를 부르는 프레젠테이션 스킬"은 빠짐
   - 팀장 소통과 영향력 → "인정받는 직장인의 구두보고 스킬"이 나오고, 같은 0.85점의 "설득 커뮤니케이션 스킬"은 빠짐
   - 데이터 분석·해석 이러닝 → ChatGPT 엑셀·PPT 과정이 나오고, Pandas·데이터 리터러시 과정은 빠짐
   - 조직 DX → 공개교육·이러닝·단체교육 3개가 모두 노션 과정
2. **오늘 개강하는 과정이 '다음 개강'으로 나온다.** 사례 1·2·5에서 2026-11-04 개강 과정이 3번 나왔다. 개강일이 빠른 순으로 고르기 때문에 당일 개강 과정이 가장 먼저 잡힌다. 카탈로그 전체에 당일 개강 과정이 10개 있다.
3. **링크 1건이 오류 페이지로 열린다.** 사례 1의 첫 과정 "[여의도] 웹 데이터(논문, 뉴스, 특허) 수집 및 비정형 보고서 작성 실무"(KMA-OFF-111311)는 HTTP 200이지만 "해당 서비스 접속이 원활하지 않습니다" 페이지가 나온다. 두 번 다시 열어도 같았다.
4. **과정명에 `&#39;`가 그대로 찍힌다.** 사례 4 PDF에 "일잘러의 필살기 &#39;업무관리 시스템&#39;"로 표시된다. 카탈로그에 이런 제목이 9개 있다(수집할 때 HTML 문자 변환을 하지 않음).
5. **개인 PDF는 4개, 참여자 화면은 6개를 보여 준다.** PDF는 `recommend_courses` 기본값(limit=4)을 써서 두 번째·세 번째 역량의 이러닝이 빠진다. 화면 설명은 "역량마다 공개교육과 이러닝 과정을 제안합니다"라서 PDF 구성과 맞지 않는다. 화면에만 나오는 과정은 `추천결과_원자료.json`의 `screen_courses`에 있다.
6. **같은 시리즈가 두 역량에 나뉘어 나온다.** 사례 1에 "직장인을 위한 AI 활용 실무 Part.1"(데이터 분석)과 "Part.2"(AI 활용)가 함께 나왔다. 제목 중복 제거가 Part 번호까지 다른 과정으로 본다.
7. **온라인 선호일 때 격차 1위 역량이 뒤로 밀린다.** 사례 3에서 차이가 가장 큰 영업 핵심역량은 이러닝 연결이 없어서 PDF 3번째에 나왔다.
8. **ESG 이러닝 연결 2건이 모두 의료기관 과정이다.** 일반 기업 조직 리포트에 "의료기관의 지속가능한 ESG 경영전략"이 나왔다.

## 수정 내용 (2026-11-04 오후)

같은 사례 5개를 수정한 코드·데이터로 다시 만들어 `수정후/`에 두었다. 추천 과정 33개(개인 6개 × 4, 조직 9개)의 링크는 모두 해당 과정 페이지가 열렸다.

| 문제 | 조치 | 수정 후 |
|---|---|---|
| 1. 같은 점수 안에서 고르는 기준 | 카탈로그 빌드: 카테고리로 잡힌 역량을 제목도 뒷받침하면 0.05 가산, 데이터 분석은 분석 제목(0.85)과 도구 제목(0.75)으로 분리, 모델 개발(머신러닝 등) 제목은 0.75로 제한. 앱: 같은 점수 안에서는 그 역량에 이미 뽑힌 과정과 주제 단어가 겹치지 않는 과정을 먼저 고름 | 설득·프레젠테이션 → "OK를 부르는 프레젠테이션 스킬", 팀장 소통 → "설득 커뮤니케이션 스킬", 데이터 분석 이러닝 → Pandas 과정, 조직 DX 3과정 → 노션·ChatGPT 자동화·AI 자동화로 갈라짐 |
| 2. 당일 개강이 "다음 개강" | 공개교육 기수 전체를 `upcoming_starts`로 싣고, 리포트를 읽는 날부터 7일 뒤 이후에 시작하는 첫 기수를 보여 줌. 그런 기수가 없으면 추천하지 않음 | 11-04·11-06·11-09·11-10 개강 과정이 모두 빠지고 가장 빠른 개강이 11-11 |
| 3. 오류 페이지 링크 | 썸네일 크롤러가 상세 페이지 834개를 모두 열어 안내 페이지("접속이 원활하지 않습니다")가 나오는 과정을 `detail_ok=False`로 기록하고 빌드에서 제외. 기수 없는 과정 129개와 기수가 있는데도 내려간 과정 6개가 걸림 | 카탈로그 1,666 → 1,572개. 링크 33개 전부 정상 |
| 4. 과정명 `&#39;` | 크롤러·빌드에서 HTML 문자를 풀고, 앱 로더에서도 한 번 더 풂 | 제목에 `&#` 남은 과정 0개 |
| 5. PDF 4개 / 화면 6개 | 개인 PDF도 6개(역량 3 × 공개교육·이러닝) | 개인 PDF 4건 모두 6개 |
| 6. 같은 시리즈 Part.1·Part.2 | 제목 정규화에서 `Part.N`, `N편/N부/N강` 꼬리를 떼어 같은 과정으로 봄 | 사례 1에서 Part.1만 나옴 |
| 7. 온라인 선호 때 격차 1위가 뒤로 밀림 | 첫 바퀴에서 선호 소스에 과정이 없는 역량은 다른 소스 과정을 받아 자리 유지 | 영업 핵심역량이 1번으로 |
| 8. 의료기관 전용 ESG 이러닝 | 제목에 의료기관·병원·간호 등이 있으면 일반 역량 연계에서 제외 | ESG 이러닝 연계 0건이 되어 조직 리포트는 공개교육·단체교육 문의로 채움 |

남은 한계
- 같은 점수에서 주제가 겹치지 않는 과정을 고르면 개강일이 먼 과정이 두 번째로 올 수 있다(사례 1 AI 두 번째 과정 2027-02-04, 사례 3 영업 두 번째 과정 2027-02-18). 역량별 첫 과정은 영향을 받지 않는다.
- ESG 이해·실천은 이러닝 후보가 없어졌다. 월간 크롤링에서 일반 기업 대상 ESG 이러닝이 들어오면 자동으로 채워진다.
- 변화 수용·추진 공개교육은 여전히 조직문화 카테고리 과정이 먼저 나온다(제목에 '변화'가 들어간 공개교육이 없음).
