# KMA TAP 상단 메뉴와 관리 화면

승인된 통합형 상단바 목업을 실제 로그인 업무 화면에 적용한다. 로고, 역할별 업무 메뉴, 프로필을 상단에 모으고 계정·프로젝트를 검색 목록과 상세 화면으로 구성한다. 서비스 소개와 로그인 경로는 유지한다.

## 역할별 이동

| 로그인 역할 | 상단 메뉴 | 최초 업무 화면 |
|---|---|---|
| KMA 관리자 | 회원사 / 계정 관리 / 프로젝트 | 프로젝트 |
| 교육담당자 | 프로젝트 / 프로젝트 만들기 / 참여자 계정 | 프로젝트 |
| 참여자 | 내 교육 | 내 교육 |

우측 프로필에는 로그인 사용자 정보와 비밀번호 변경·로그아웃을 표시한다. 최초 비밀번호 변경이 필요한 계정은 업무 메뉴를 사용할 수 없고 비밀번호 설정과 로그아웃만 가능하다. 비밀번호 변경 화면에서도 상단 업무 메뉴를 누르면 해당 업무로 돌아간다.

## 변경 파일

| 파일 | 역할 |
|---|---|
| `tap/account_navigation.py` | 서버가 확인한 역할로 메뉴 생성, 선택 상태 유지, 프로필 이동 |
| `tap/account_portal.py` | 인증 후 상단바 렌더링과 업무·비밀번호 화면 연결 |
| `tap/account_admin_ui.py` | 계정·프로젝트 검색 목록과 상세, 기존 등록·배정·재발급 기능 연결 |
| `tap/account_theme.py` | 운영 화면 전용 CSS 로딩 |
| `assets/workspace-ui.css` | 상단바, 검색 목록, 상세 카드와 모바일 배치 |
| `tap/account_guide.py` | 역할별 상단 메뉴와 프로필 이용 안내 |
| `tests/test_account_portal.py` | 인증 경계와 상단 메뉴 이동 회귀 검증 |

상단 메뉴는 Streamlit 기본 버튼과 상태를 사용하고 프로필은 기본 popover를 사용한다. 별도 프런트엔드 프레임워크, iframe, 외부 로그인 서비스는 추가하지 않는다.

## 보존하는 기능과 권한

- 이름·ID·회사 계정 검색과 회사·프로젝트·교육명 검색을 유지한다. 부분 일치와 영문 대소문자 무시 규칙도 유지한다.
- 교육담당자의 회사 범위는 기존 저장소 권한 검사를 그대로 적용한다. 메뉴 선택값이 역할이나 회사 권한을 부여하지 않는다.
- 현재 역할에 없는 선택값은 기본 업무로 정리한다. 참여자는 세션이나 주소에 관리자 값을 넣어도 참여자 화면만 렌더링한다.
- 회사·계정·프로젝트 생성, CSV 참여자 등록, 프로젝트 배정, 임시 비밀번호 재발급, 계정 사용 중지와 기존 검색 기능을 유지한다.
- 검사 응답 저장과 사전·사후 비교, 비밀번호 정책, 최초 비밀번호 변경 요구, 토큰 회전은 기존 구현을 사용한다. 이번 UI 변경으로 데이터 스키마를 바꾸지 않는다.
- 로그아웃과 비밀번호 변경 성공 시 기존 인증·발급정보 정리 과정에 따라 메뉴 상태도 초기화된다. 일반적인 화면 재실행에서는 선택한 업무 메뉴를 유지한다.

## 검증

로컬에서 `python -B -m unittest tests.test_account_portal -v`로 포털 테스트 12개가 통과했다. 기존 인증 테스트 5개에 역할별 메뉴, 선택 유지, 회사·참여자 권한 밖 이동 차단, 프로필 닫힘과 업무 복귀, 최초 비밀번호 변경 차단, 비밀번호 저장 후 토큰 회전을 검사하는 7개 테스트를 추가했다. 기존 로그아웃 테스트는 새 메뉴 상태 삭제도 확인한다.

상태가 있는 popover는 Streamlit 1.61 AppTest에서 기본 직렬화 대상이 아니므로 테스트가 브라우저와 같은 boolean 상태를 전달한다. 테스트용 저장소와 가상 사용자만 사용하며 실제 계정이나 응답을 변경하지 않는다.

배포 검증에는 전체 회귀 테스트, PostgreSQL 검증, 역할별 화면과 모바일 상단바·프로필 확인을 포함한다. 배포 실행 결과는 해당 커밋의 CI 및 배포 기록에서 확인한다.
