# TAP 교육평가 검토보고서 v2

## 한 문장 결론

현재 TAP은 **교육수요를 탐색하는 자기보고형 업무행동 점검 도구**로 사용할 수 있지만, 아직 **학문적으로 타당화된 역량검사**로 표현하거나 개인·조직의 역량 순위를 확정할 단계는 아닙니다.

## 교육 전후 평가 설계

이번 MVP는 일회성 교육수요 진단을 `사전검사 → 교육·현업 적용 → 사후검사 → 변화·전이 리포트`로 확장합니다.

- `사전검사(T0)`: 교육 전에 최근 8주의 실제 업무행동을 기록합니다.
- `사후검사(T2)`: 교육 직후가 아니라 현업 적용 기회가 생긴 기본 8~10주 뒤, 동일한 행동문항·척도·회상기간으로 다시 측정합니다. `최근 8주` 회상기간이 교육 전 시점을 포함하지 않도록 교육 8주 이후에 시작합니다.
- `현업 적용환경`: 사후에 적용기회, 상사지원, 도구, 권한, 프로세스 장애를 별도로 묻습니다. 낮은 변화가 곧 학습 실패를 뜻하지 않도록 업무환경을 함께 해석합니다.
- `짝지은 비교`: 동일 참여자의 동일 역량에 사전·사후 유효점수가 모두 있고 문항 버전이 같을 때만 변화값을 계산합니다. 미응답과 `수행 기회 없음`은 0점으로 대체하지 않습니다.
- `결과 표현`: 비교집단이 없는 자기보고식 전후 비교는 `교육 전후 관찰된 변화`입니다. 교육이 변화를 일으켰다는 인과효과로 표현하지 않습니다.

교육 직후 지식·판단·수행을 확인하려면 향후 별도의 `직후 학습검사(T1)`를 과정 목표에 맞는 지식문항, 상황판단문항 또는 수행과제로 추가해야 합니다. 동일 행동문항을 교육 직후 반복하는 것만으로 학습성과를 판단하지 않습니다. 더 강한 효과 추론이 필요하면 비교집단 또는 대기집단을 두고 사전 차이, 이탈, 교육 참여량을 함께 관리합니다.

## 전수 대조 결과

- 첨부 엑셀과 배포 데이터의 문항코드·역량코드·수정문구·판정·대상수준·배점 필드를 전수 대조했습니다.
- 144문항 중 운영 124문항, 36역량 중 운영 31역량으로 일치했고 핵심 필드 불일치는 없었습니다.
- 운영 124문항 모두 `전문가 예비검토·인지면접 전` 상태입니다.
- 직급 20문항을 별도 점수에서 제외하고, 역문항을 직접채점 문구로 바꾸고, 종합점수·T점수·백분위를 제공하지 않는 방향은 적절합니다.

## 즉시 바로잡은 해석·운영 문제

1. `validity_score`를 타당도처럼 평균 10점으로 표시하던 화면을 제거했습니다. 이제 `설계검토 충족수`로 표시하고 인지면접 완료 수를 별도로 보여줍니다.
2. 미응답과 `수행 기회 없음`이 모두 0으로 합쳐지던 채점 로직을 분리했습니다.
3. 1~5 평균의 수준 구간은 검증된 기준이 아니므로 `임시 기술구간`으로 명시했습니다.
4. 개인 리포트가 최저점 역량 하나를 확정적으로 지목하던 문구를 `개발 맥락을 살펴볼 후보`로 낮췄습니다.
5. 0~100 값은 백분율·백분위·숙련도가 아니라 `(평균−1)×25`인 선형 환산지수임을 표시했습니다.
6. 조직 리포트에 N, 공개/보호 상태, 목표 출처, 해석 제한과 도구의 검증상태를 함께 표시했습니다.
7. 참여자 화면에서 역량명을 숨기고 문항 순서를 프로젝트별로 안정적으로 섞어 바람직한 답을 추측하는 단서를 줄였습니다.

## 우선 재검토가 필요한 기존 문항

다음 문항은 이중질문, 내용 중복, 낮은 수행기회 또는 역량 정의와의 불일치 위험이 상대적으로 큽니다. 앱에서 임의로 확정 수정하기보다 교육평가 전문가와 직무전문가가 함께 검토해야 합니다.

| 문항 | 핵심 위험 | 검토 방향 |
|---|---|---|
| `Q-ST-03` | 단기·중장기 균형 문항과 중복 | 자원배분 행동으로 교체 검토 |
| `Q-PD-04` | 심리적 안전감을 직접 측정하지 않음 | 우려·실수 제기에 비난 없이 반응하는 행동 |
| `AI_USE_Q2` | 사실·출처·오류의 복합 질문 | 핵심 사실의 출처 대조로 단일화 |
| `AI_USE_Q4` | 입력정보 보호와 결과검토 혼합 | 개인정보·기밀 제외 행동으로 단일화 |
| `PLAN_Q1` | 실행단계·담당·기한의 복합 질문 | 실행단계와 책임·기한을 분리 |
| `DATA_Q2` | 분석과 시각화 혼합 | 분석방법 선택과 시각화 문항 분리 |
| `PM_Q4` | 종료 회고만 있고 진행통제 부족 | 계획 대비 진행상태 점검으로 교체 검토 |
| `COMM_Q4` | 이메일 문항이 프레젠테이션 정의와 불일치 | 발표 질의응답 또는 역량명 변경 |
| `SALES_Q4` | 일반 실행력과 중복 | 고객 맞춤 제안 행동으로 교체 검토 |
| `DEV_Q2` | 구현·시험·배포가 과소대표 | 코드 변경 후 자동화 테스트 확인 |
| `PR_Q3` | 8주 내 위기 발생 가능성이 낮음 | 승인 경로의 모의 점검 행동 |
| `DATAJOB_Q2` | 정의의 모델링을 측정하지 않음 | 모델 선택·검증·재현성 문항 추가 |

## 내용 대표성이 부족한 역량

- `성장 마인드셋`: 태도 정의와 행동빈도 문항이 어긋납니다. 행동도구를 유지하려면 `학습·개선 행동` 같은 명칭이 더 정확합니다.
- `전략적 사고`: 단기·장기 균형 내용이 중복되고 자원배분 행동이 약합니다.
- `사람 육성`: 심리적 안전감이 직접 측정되지 않습니다.
- `프로젝트 실행·관리`: 착수·위험·역할·회고는 있으나 진행통제와 변경관리가 부족합니다.
- `설득·프레젠테이션`: 이메일 작성은 있으나 발표전달과 질의응답이 없습니다.
- `ESG 이해·실천`: 환경·사회·지배구조를 4문항의 단일 평균으로 대표하기 어렵습니다.
- `변화 수용·추진`: 개인의 변화 적응과 리더의 변화 추진이 한 점수에 섞여 있습니다.
- `개발 핵심역량`, `데이터 분석 전문역량`: 구현·시험·보안 또는 모델 선택·검증을 충분히 표집하지 못합니다.

직무역량의 4문항은 하나의 단일요인 척도라기보다 서로 다른 업무영역을 한 개씩 표집한 **형성적 프로필**에 가까울 수 있습니다. 파일럿 전에는 단순 평균의 의미를 확정하지 말고 문항별 프로필 또는 세부영역 확장을 검토해야 합니다.

## 추가한 파일럿 후보 4역량·16문항

운영 점수에는 포함하지 않고 `data/pilot_item_candidates.csv`에 분리했습니다.

| 후보 역량 | 대상 | 보완하려는 공백 |
|---|---|---|
| 업무 소통 | 전 직급 | 실무자 기본경로의 경청·명료화·적시 공유 |
| 책임 있는 판단 | 전 직급 | 근거 기록·오류 공개·준법 판단·불확실성 표시 |
| 디지털 안전·정보판별 | 전 직급 | 출처 신뢰성·개인정보·링크 안전·최소권한 |
| 성과관리와 책임 | 관리자·임원 | 기대결과 합의·진행점검·장애 제거·후속조치 |

이 문항은 **직무분석·전문가 검토·인지면접 전 초안**이며 프로젝트 선택과 점수 산출에서 비활성입니다. 특히 윤리·안전 영역은 사회적 바람직성이 높으므로 상황판단 문항이나 객관자료를 병행하는 것이 좋습니다.

## 배점과 추천 알고리즘의 해석 제한

- 4문항 중 3문항 평균 규칙, 1~5 평균, 임시 수준구간은 운영가정이며 실증 근거가 아닙니다.
- 모든 역량에 동일한 목표 3.5를 쓰면 직급·직무의 기대행동 차이를 반영하지 못합니다.
- 목표 3.5일 때 격차 배점의 실제 최대는 25점이므로 `격차 최대 40점`은 가능한 이론상 상한일 뿐입니다.
- `혼합 또는 미확인`에 0.5를 일괄 곱해도 과정 순위는 바뀌지 않습니다. 이는 불확실성 표시로만 해석해야 합니다.
- 과정 적합도는 학습목표–연습–평가와 행동지표를 2인 이상이 독립 매핑하고 합의 근거를 남겨야 합니다.
- 조직의 N=5 공개 기준은 개인정보 보호 규칙이지 평균의 안정성을 보장하는 통계 기준이 아닙니다.

## 배포 전 최소 타당화 순서

1. 회원사 직무분석으로 과업–역량–행동지표와 중요도·빈도를 확정합니다.
2. 교육평가 전문가와 직무전문가가 독립 내용검토 후 합의합니다.
3. 직급·직무·조직을 의도적으로 포함해 인지면접을 수행합니다.
4. 파일럿에서 NA율, 미응답, 천장·바닥효과, 반응시간, 문항변별을 분석합니다.
5. 핵심역량은 요인구조, 오메가 신뢰도, 측정동일성을 검토합니다.
6. 직무역량이 단일요인 척도인지 형성적 지수인지 먼저 결정합니다.
7. 개인차·사전사후차·집단평균 각각에 맞는 신뢰도와 표준오차를 산출합니다.
8. 교육과정 가중치와 콘텐츠 매핑을 별도로 검증하고 민감도 분석을 수행합니다.
